# CourseReg — Oracle 23ai DBMS Project UI

A React + Vite course registration management dashboard recreated from the supplied reference screens.

## Included
- Dashboard
- Student Management
- Department Management
- Instructor Management
- Course Catalog
- Course Sections
- Registration Management
- Academic Reports
- Search/filter controls
- Add/Edit/Delete modal interactions
- Responsive mobile sidebar
- Lucide icon-only UI (no emoji)
- Flat, restrained colors with no high-gradient backgrounds

## Run
```bash
npm install
npm run dev
```

Open the local URL shown by Vite, usually `http://localhost:5173`.

This is a frontend demo with local React state. Connect the form actions to your Oracle/API layer for persistent database operations.
